# Patch Notes

## Legacy Upgrade Rework
- Legacy Upgrade is redesigned in a skill tree style, instead of a list of boosts
- Legacy Upgrade cost is changed: 1st upgrade costs 1 legacy point, 2nd costs 2 legacy points...
- Legacy Upgrade has more stats boosts, as well we new game mechanics

# Other Changes
- Support scaling UI (Settings -> General -> UI Scale)
- Support turning off Todo icons on the left
- Demand Tile now checks that the tile is not contested in an active war
- Force Attack duration increased from 6 to 12 months
- Fix a bug where importing goods incorrectly increase monthly income (it should decrease it)
