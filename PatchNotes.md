## Dominion Point

Added Dominion Points (DP), replacing cooldowns for coring, pillaging, cultural conversion, and religious conversion (Evangelize and Invite to Islam).

- Each action costs 1 DP in addition to its existing resource costs. Actions can be repeated immediately while affordable; pillaging still removes one development level per action.
- Base generation is 1 DP every January, with a starting capacity of 5. Gains above capacity are discarded before automatic actions spend points. New games start with 5 DP.
- Curial Reform and Local Governance each increase yearly Dominion Points by 50%. Legal Code and Territorial Integration each increase Dominion Points Capacity by 5.
- Added four legacy upgrades for yearly Dominion Points and four for Dominion Points Capacity. Each grants +50% yearly generation or +5 capacity, respectively. Generation bonuses stack additively.

## Balance Changes

- Added another legacy upgrade tier for Monthly Military Points, Infantry Unit Power, Ranged Unit Power, Cavalry Unit Power, War Power, and Starting General Skill Points.
- Reorganized the infiltration and trade-attitude legacy branches around the new Dominion upgrades. Some upgrades now require additional prerequisites.
- Dismissing a general now starts a 5-year General Appointment cooldown for both recruiting a new general and appointing the governor as general.

## Bugfixes

- Game events with no available options now provide a default acknowledgement option.
